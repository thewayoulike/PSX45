# Public market reports

Daily source snapshots for PSX Tracker. No portfolio or account data. This branch does not deploy on Vercel.

Investor flows use SCS Trade’s public FIPI/LIPI report. Insider history is partial: the provider exposes the latest five records per company, and daily updates retain previously collected records. Source dates and links are included. Gifts, transfers and unpriced trades are excluded from buying/selling totals in the app.
